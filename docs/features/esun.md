# 玉山證券行情

用玉山證券帳戶免費取得盤中即時行情：全市場快照、分 K、日 K 與 WebSocket 即時推播。玉山行情和富果行情是同一套 API（同一台伺服器、相同路徑與欄位），所以熱浪圖、時光機、即時看板、異動雷達、自訂提醒、當沖監控與五檔錄製器都能直接使用，效果和富果相同。

## 在哪裡

「資料與設定 → 資料來源 → 玉山證券行情」。金鑰欄位填**玉山設定檔 config.ini 的完整路徑**（路徑不可有空白）。

## 事前準備

| 步驟 | 說明 |
|---|---|
| 1. 申請 API | 在玉山「交易 API 金鑰網站」申請憑證、簽署 API 服務同意書、完成模擬下單，取得正式環境設定檔（config.ini）與 .p12 憑證，並把這台電腦的 IP 加入白名單 |
| 2. 安裝行情 SDK | 以 pip 安裝玉山提供的 Python 行情 SDK（`esun_marketdata` 的 .whl）。衡析預設執行 `python3`；SDK 裝在其他 Python 時，以環境變數 `ESUN_PYTHON` 指定完整路徑 |
| 3. 輸入密碼一次 | 在終端機執行 `python3 EquiLens-Nexus/tools/esun-token.py /路徑/config.ini --setup`，依提示輸入登入密碼與憑證密碼。密碼由玉山 SDK 存在系統鑰匙圈（`esun_trade_sdk:account`、`esun_trade_sdk:cert`），衡析不經手 |
| 4. 在衡析設定 | 資料來源勾選「玉山證券行情」，貼上設定檔路徑後按「驗證並儲存」 |

macOS 第一次從背景程式讀取鑰匙圈時，可能會跳出「允許存取」視窗，請按允許。

設定檔可以是 UTF-8（含或不含 BOM）或 Big5 純文字，需含 `[User]` 區段與 `Account`。若顯示「設定檔格式錯誤」，訊息後的括號會說明原因（例如 `rtf` 表示被 macOS「文字編輯」存成格式化文字，請改用「格式 → 製作純文字」後再存；或列出實際找到的區段與欄位名稱，不含設定值）。

## 權限與額度（玉山官方方案，皆免費）

| 方案 | WebSocket | 盤中 REST | 全市場快照 | 歷史行情 | 條件 |
|---|---|---|---|---|---|
| 基本用戶 | 5 訂閱數／1 連線 | 每分鐘 60 次 | 不支援 | 每分鐘 60 次 | 有玉山帳戶並通過申請 |
| 開發者 | 300 訂閱數／2 連線 | 每分鐘 600 次 | 每分鐘 600 次 | 每分鐘 60 次 | 完成模擬下單 |
| 進階用戶 | 2,000 訂閱數／3 連線 | 每分鐘 2,000 次 | 每分鐘 2,000 次 | 每分鐘 60 次 | 上個月交易量達 1,000 萬 |

驗證時會試一次全市場快照：可用就視為開發者以上（熱浪圖等功能可用），不可用就視為基本用戶。訂閱數算法與富果相同（1 檔 × 1 個頻道），當沖完整模式每檔 3 個訂閱。

## 運作方式

1. 衡析在背景執行 `tools/esun-token.py`：用玉山官方行情 SDK 讀取設定檔與 .p12 憑證登入，換取行情 token，以一行 JSON 回傳。這支程式**只呼叫登入與取得行情 token**，不使用任何下單、改單或帳務功能，也不匯入交易 SDK。
2. 之後的行情請求由衡析直接送到 `https://api.fugle.tw/marketdata/v1.0/stock`，以 `X-SDK-TOKEN` 標頭驗證；WebSocket 以 `{ event: 'auth', data: { sdkToken } }` 驗證。其餘處理與富果完全相同。
3. token 效期沒有公開說明：每 6 小時重新登入一次；請求被拒（401／403）或推播驗證失敗時立即重新登入（強制重新登入至少間隔 1 分鐘）。
4. 背景執行時不會等待輸入：鑰匙圈沒有密碼時直接回報「請先執行 --setup」。

## 注意事項

- 玉山的設定檔、憑證與金鑰同時具有交易權限。衡析只使用行情功能；請不要把設定檔與憑證放在雲端同步資料夾或分享給別人。
- 依玉山使用規範，行情只能自己使用，不得轉接或傳送給第三人：不要把手機版網址分享給別人。
- 成交量值不含零股及鉅額交易（與富果相同）。歷史分 K 只有近 5 日。
- 玉山保留隨時變更或終止免費方案的權利；銷戶後權限取消。
- 券商分點、當沖盤前資料（可當沖標的等）不在玉山行情內，仍需 FinMind Sponsor。
