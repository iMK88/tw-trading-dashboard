# 衡析 App 隱私權政策

最後更新：2026-10-27

衡析（EquiLens）App 是開放原始碼的研究工具。App 本身不提供行情資料，也不經營帳號系統。資料與金鑰都放在你自己電腦上的衡析，App 透過你設定的網址連回該電腦。

## App 處理哪些資料

| 資料 | 存放或傳送到哪裡 | 用途 |
|---|---|---|
| 你輸入的衡析網址、最近連過的網址 | 只存在這支手機 | 下次開啟時自動連線 |
| 登入狀態（Cookie） | 這支手機，以及你自己的電腦 | 保持登入，最長 30 天 |
| 推播代碼（Firebase Cloud Messaging token） | 你自己的電腦；發送通知時傳給推播中繼服務與 Google／Apple 的推播服務 | 把通知送到這支手機 |
| 通知內容（例如股票名稱、提醒條件、新聞標題） | 由你的電腦經推播中繼服務、Google Firebase 與 Apple 推播服務送到手機 | 顯示通知 |
| 你在 App 中查看的研究資料 | 你自己的電腦 | App 畫面 |

- **推播中繼服務**由 App 發行者營運，只負責把你的電腦送來的通知轉交給 Firebase。它不保存通知內容或推播代碼，只在記憶體中暫時計算傳送頻率，用來防止濫用。
- **只有開啟通知才會使用推播代碼**。你可以在「盤中 → 雷達」關閉通知，或在手機設定中關閉衡析的通知。
- 行情、籌碼與新聞資料都由你自己的電腦，向你設定的資料源（例如 FinMind、富果、證交所）取得。App 發行者無法取得這些資料。

## App 不做的事

- 不收集姓名、電子郵件、位置、聯絡人或相簿內容。
  - 儲存圖卡時，圖片會寫入你的相簿（Android）或交給系統分享選單（iPhone）。App 不讀取相簿。
- 沒有廣告。
- 沒有分析或追蹤工具。
- 不跨 App 或網站追蹤你。
- 不出售或分享任何資料。

## 示意模式

示意模式使用 App 內建的合成示意資料，不連線到任何伺服器，也不傳送任何資料。

## 第三方服務

| 服務 | 用途 | 隱私政策 |
|---|---|---|
| Google Firebase Cloud Messaging | 推播通知 | https://firebase.google.com/support/privacy |
| Apple Push Notification service（iPhone） | 推播通知 | https://www.apple.com/legal/privacy/ |
| Cloudflare Workers | 推播中繼服務的執行環境 | https://www.cloudflare.com/privacypolicy/ |

## 刪除資料

- 解除安裝 App，就會刪除手機上的網址、登入狀態與推播代碼。
- 在電腦版衡析刪除 `EquiLens-Pocket/.local/` 中的資料，或關閉這支手機的通知，就會刪除你電腦上的這些資料。
- App 發行者沒有保存你的任何資料，因此不需要另外申請刪除。

## 兒童

衡析是給成年投資研究者使用的工具，不以兒童為對象。
